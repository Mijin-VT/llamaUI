> Branch: `ui-overhaul`  
> Goal: Eliminate "AI slop" aesthetic and replace with a cohesive, professional desktop UI.

## 2. Design System

### Philosophy
- **Dense, not sparse** — this is a developer tool, not a marketing site.
- **Muted, not neon** — semantic colors should be desaturated. Accents should be subtle.
- **Aligned, not centered** — forms use left-aligned grids, not floaty centered layouts.
- **Consistent, not clever** — one radius scale, one spacing scale, one type scale.

### Color Palette (Dark Mode)

| Token | Value | Usage |
|---|---|---|
| `bg-app` | `#0f1117` | Deepest background |
| `bg-surface` | `#161922` | Cards, panels, sidebar |
| `bg-surface-hover` | `#1c1f2a` | Hover states |
| `bg-elevated` | `#1e222d` | Inputs, elevated elements |
| `bg-inset` | `#0a0c10` | Logs, code blocks, deepest inset |
| `border` | `#2a2e3b` | Default borders |
| `border-subtle` | `#1e2129` | Dividers, separators |
| `text-primary` | `#e2e4e9` | Headings, primary text |
| `text-secondary` | `#9aa0b2` | Labels, descriptions |
| `text-muted` | `#6b7280` | Placeholders, disabled |
| `accent` | `#0ea5e9` | Sky blue — calm, professional, NOT purple |
| `accent-hover` | `#38bdf8` | Hover state |
| `accent-dim` | `#0ea5e920` | Tinted backgrounds |
| `success` | `#22c55e` | Green — muted, not neon |
| `warning` | `#f59e0b` | Amber |
| `error` | `#ef4444` | Red — only for destructive actions |
| `info` | `#3b82f6` | Blue |

> Why sky blue? It is the most common "professional" accent in modern dev tools (VS Code, Cursor, GitHub Dark). It does not scream "generated by AI."

### Spacing Scale (px)

`0, 2, 4, 6, 8, 10, 12, 16, 20, 24, 32, 40, 48`

### Typography

| Role | Size | Weight | Line-height |
|---|---|---|---|
| Page title | 20px | 600 | 1.3 |
| Section title | 16px | 600 | 1.3 |
| Card title | 14px | 600 | 1.3 |
| Body | 13px | 400 | 1.5 |
| Label | 12px | 500 | 1.3 |
| Caption | 11px | 400 | 1.3 |
| Mono | 12px | 400 | 1.4 |

### Radius Scale

| Token | Value | Usage |
|---|---|---|
| `radius-sm` | 4px | Inputs, small buttons, badges |
| `radius-md` | 6px | Buttons, cards |
| `radius-lg` | 8px | Panels, modals |
| `radius-full` | 999px | Pills, chips |

## 3. React / Tauri Implementation Plan

### 3.1 Add Mantine v7

Install:
```bash
npm install @mantine/core @mantine/hooks @mantine/notifications @mantine/form
npm install -D postcss postcss-preset-mantine
```

Configure `postcss.config.cjs` and wrap `<App />` in `<MantineProvider>` with the custom dark theme override.

### 3.2 Theme Override

Create `src/theme.ts` exporting a custom Mantine theme that maps exactly to the Design System above:
- `colors.dark` array mapped to our bg/text tokens
- `primaryColor: 'blue'` with `['#0ea5e9', '#38bdf8', ...]`
- `fontFamily` set to `Inter, system-ui, sans-serif`
- `fontFamilyMonospace` set to `JetBrains Mono, monospace`
- `radius` mapped to scale
- `spacing` mapped to scale
- `fontSizes` mapped to type scale

### 3.3 Global CSS Reset

Replace `src/styles.css` with a minimal reset + Mantine-compatible overrides:
- Scrollbar styling
- Selection color
- WebKit tweaks

### 3.4 Component-by-Component Migration

Migrate each page from raw HTML → Mantine components:

| Page | Key Changes |
|---|---|
| **App.tsx** | `Tabs` for nav bar instead of custom buttons |
| **SetupPage** | `Card`, `TextInput`, `NumberInput`, `PasswordInput`, `Button`, `Badge`, `Group`, `Stack`, `Grid`, `Table`, `Divider` |
| **RunPage** | `Select`, `Slider`, `Switch`, `Accordion`, `Code`, `Tooltip`, fix `.run-*` missing styles |
| **DownloadPage** | `Progress`, `ScrollArea`, `Skeleton` |
| **HfModelPage** | `TextInput`, `Badge`, `Accordion`, `Markdown` |
| **StatusPage** | `Timeline`, `Code`, `CopyButton` |
| **DiagnosticsPage** | `List`, `Code`, `Badge` |

### 3.5 Layout Fixes

- Remove all inline `style={{ ... }}` props.
- Use Mantine `Grid` / `Group` / `Stack` / `Flex` for all layouts.
- Ensure `whiteSpace: 'nowrap'` on buttons with `truncate` on overflow text.
- Add `minWidth` and `maxWidth` constraints via theme, not hardcoded CSS.

## 4. Qt App Implementation Plan

### 4.1 Redesign `theme.py`

Replace all color tokens with the Design System palette:
- `BG_APP = "#0f1117"`
- `BG_SIDEBAR = "#161922"`
- `BG_PANEL = "#1e222d"`
- `ACCENT = "#0ea5e9"`
- `ACCENT_HOVER = "#38bdf8"`
- `ACCENT_PRESSED = "#0284c7"`
- `SUCCESS = "#22c55e"`
- `WARNING = "#f59e0b"`
- `DANGER = "#ef4444"`

### 4.2 Fix Typography

- Convert all `pt` sizes to `px`.
- Scale down sidebar brand from 22pt → 16px.
- Scale down page titles from 16pt → 18px.
- Scale down card titles from 12pt → 14px.
- Body stays at 13px.

### 4.3 Fix Button Sizing

- Remove `max-width: 220px` from base `QPushButton`.
- Reduce padding from `8px 18px` → `6px 14px`.
- Reduce font-size from `10pt` → `12px`.
- Add `min-width: 80px` so short labels don't look tiny.

### 4.4 Fix Input Sizing

- Remove global `max-width: 320px` from inputs.
- Let layouts control width via `stretch` factors.
- Keep `min-width: 120px` as a sensible floor.

### 4.5 Fix Card Appearance

- Reduce border-radius from `10px` → `8px`.
- Standardize card padding to `16px` all around.

### 4.6 Fix Layout Issues Per Page

| Page | Fix |
|---|---|
| **Settings** | Use `QGridLayout` with consistent columns instead of mixed `QHBoxLayout` + `setFixedWidth`. Fix HF token section alignment. Add path display to Model Download Directory card. |
| **Library** | Fix badge overflow — use `ElidedLabel` or tooltips. Ensure model picker dropdown stretches. |
| **Run** | Fix button row alignment. Ensure dropdowns use `sizePolicy = Expanding`. Fix slider+spinbox height mismatch. |
| **Discover** | Fix table column sizing — let Repo column stretch. Remove double scrollbars. |
